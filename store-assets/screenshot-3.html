Write a bash script to rename .jpg files by EXIF date?
🤖 Claude
Here's the script: 
#!/bin/bash
for file in *.jpg; do
  date=$(exiftool -d "%Y%m%d" \
    -DateTimeOriginal "$file")
  mv "$file" "${date}_${file}"
done
Use: chmod +x rename-by-date.sh && ./rename-by-date.sh
